## 第三轮：Prism 光谱配色（完成）

用户反馈 "don't like black and write, too simple, want more bright / colorful / technical innovative, like purple or blue, can mix other colors"。**推翻第一轮的 refined corporate 单色海军蓝方向**。

**新美术方向：Prism / Spectral Systems** —— 颜色是数据通道而非装饰：
violet = Agent 系统、blue = 平台、cyan = 数据/事件、amber = 电商、magenta = 实时/可交互状态。
`--signal` 从 signal-lime 改为 magenta。两套主题都彩色：**light = Prism（亮，默认）**，**dark = Nebula（深靛紫 + 发光光谱，不再是近黑）**。文字是深靛紫墨色，背景是淡薰衣草白，都不是纯黑白。

**实现要点**
- `index.css` 末尾追加 `SPECTRAL LAYER`：新的 `--c-violet/blue/cyan/amber/magenta/teal` vivid 原语、`--spectrum` / `--spectrum-btn` 渐变、`--ink-*` 可读变体、`--aurora-1..4`、重定义两套 semantic token（含 `--signal*`、`--hue-*`、`--code-*`、`--shadow-*`）。**用文件末尾覆盖而非改散落各处的原值**，保持两层 token 结构。
- body 四层 `radial-gradient` + `background-attachment: fixed` 的全站极光；`.hero::before` 局部漂移极光；`.section` / `:nth-of-type(even)` 各自的本地 wash + `.section--bordered` 的 `border-image` 渐变分隔线（保证全页截图/不支持 fixed 的浏览器也有颜色）。
- 光谱元素：header 渐变细线、渐变 CTA（hover 位移）、kinetic 标题渐变文字（`background-clip:text` + 慢速 prism-shift）、scroll-progress / trace-rail 渐变、彩色 metric 数字与 sparkline、彩色 marquee、项目卡顶部渐变线 + 图表底色染色、capability 图标按 nth-child 分色、lab 步骤图标分色/渐变影响条、命令面板渐变顶边。
- 新增 `SpectrumKey.jsx`（CHROMATIC KEY 五个色卡）放在 Hero meta 下；把颜色编码显式写出来，是"技术感"而非"堆渐变"的关键。
- `SystemGraph.jsx`：4 节点/4 条边各带 `--node-hue` / `--edge-hue`，选中色通过 `--inspector-hue` 传播到读数区；core 改三色渐变描边。
- `Logo.jsx` / `favicon.svg` 改渐变 monogram（`useId` 避免重复 gradient id）。
- `ProjectCard.jsx` 传 `--pv-accent` 到卡片本身；`Reveal.jsx` 增加 `style` 合并（此前 `{...rest}` 会覆盖 `--reveal-delay`）。
- **默认主题改为 light**：`index.html` 的 `data-theme` / theme-color / 防 FOUC 脚本、`useTheme.js` 三处默认值；storage key 升级为 `portfolio_theme_v2`，让新默认对老访客生效。`commit()` 同步更新 theme-color meta。

**验证（Chrome + CDP）**

## 第四轮：小字可读性 / CLARITY LAYER（完成）

用户反馈 "some small size words seems too vague, can you make it more clear" —— 指小字号、低对比、全大写宽字距的模糊感。

**根因**：全站有 **66 条** micro-label 规则落在 8.8–11.5px，多为 mono + uppercase + 0.10–0.16em 字距 + `--text-faint`；SVG 图内文字是 viewBox 用户单位（会随卡片进一步缩小），实际只有 8px 左右。

**做法：`index.css` 末尾追加 CLARITY LAYER（覆盖式，不动散落原值，且只改 size / weight / tracking / ink，绝不改 hue，保留第三轮的颜色编码）**
- 新增 token：`--text-xs` 12→13px、`--text-sm` 14→14.4px、`--micro` 12.5px 硬下限、`--micro-lg` 13.4px（eyebrow / 章节号）、`--micro-track` 0.055em（原 0.10–0.16em）。
- 两套主题都加深次级墨色：light `--text-3` 43→37%、`--text-faint` 48→40%；dark 72→81% / 62→74%；同步 `--code-comment`。
- 一组选择器把 ~50 个 micro label 统一拉到 12.5px / 600 字重；eyebrow + 章节号 13.4px / 650；短描述 500 字重 + `--text-2`；code/kbd/trace 单独 11.8–12.2px 且字距归零。
- SVG：`pv-label` 10→12px、`pv-label--strong` 11→13.5px、`pv-label--accent` 9→11.5px、sg node 11→13px / sub 8.5→11px；靠把 tracking 归零换取宽度，逐个 `getBBox()` 验证 44 个 text 均未越出节点框。`ProjectVisual.jsx` 把过长的 "DURABLE EXECUTION GRAPH" 缩短为 "DURABLE EXECUTION"。
- `body` 改回 `-webkit-font-smoothing: auto`（antialiased 会让小字更细）。
- 面板标题栏给 `.sg-req::before` 加 1px 竖分隔线，区分 "topology.live" 与请求计数两个读数。

**顺带修掉 3 个真实 bug**
1. 移动端 Hero 单列 grid 的隐式 auto track 被 `.sg-trace`（white-space:nowrap）撑到 398.9px，`.hero` 又 `overflow:hidden`，导致每行右侧约 29px 文字被静默裁掉（"distributed servic…"）。修法：`@media (max-width:979px) .hero__grid { grid-template-columns: minmax(0,1fr) }` + `.hero__grid > * { min-width:0 }` + `.sg-trace/.sg-trace__line { min-width:0 }`。
2. ≤430px 时 brand(224) + gap(20) + actions(136) = 380 > 350 可用宽，汉堡按钮右沿到 400px 被 `.site` 裁掉。修法：该断点内 brand subtitle 允许折成两行（`.brand__name { max-width:118px }`、span `white-space:normal`）+ 缩小 header gap。
3. `useTheme.js` 的 `startViewTransition` 在快速切换/导航时会 reject `ready`/`finished`，产生 "Uncaught (in promise)"。修法：对两个 promise 挂 `.catch(() => {})`。

**验证**：build 通过（65 modules，CSS 100.82 kB / JS 275.05 kB）。Chrome CDP 实测：WCAG light `--text` 16.33:1 / `--text-faint` 8.89:1，dark 17.27:1 / 8.23:1；micro label 最小 12.5px（eyebrow 13.4px）；44 个 SVG text 无越框；1000–1600 六档 header 无折行、390/768/1000/1440 无横向溢出；8 条路由 390px 逐元素越界审计仅剩 marquee（设计如此）；10 路由 + 命令面板/拓扑/实验室/主题切换全通过；**0 uncaught exception / 0 console error**。
